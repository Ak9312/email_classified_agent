# Job Email Agent

Job Email Agent is a personal tool that adds one of four labels to emails in my own job-search Gmail account:

- **Interview / Recruiter**
- **Job Alerts**
- **Rejections**
- **Other**

It is used only by its owner. It is not a public service and does not access anyone else's account.

It only adds labels. It never deletes, archives, sends, or marks emails as read.
